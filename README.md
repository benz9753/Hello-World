# Hello-World: BAIS Professional Portfolio

> My first practice repository for BAIS:3050 Professional Preparation.

## Description
This repository is a small **professional portfolio** showing work from my
Business Analytics & Information Systems coursework at the University of Iowa.
I created it to practice organizing and documenting project files on GitHub.

## Tools Used
- Microsoft Excel
- DBeaver
- GitHub
- SQL

## Files Used
| File | Description |
|------|-------------|
| `chinook_queries.sql` | SQL queries analyzing sales data in the Chinook database |
| `capital_budgeting.xlsx` | NPV and IRR analysis for a capital budgeting decision |


## How to Run Program
1. Download both files from this repository.
2. Open `chinook_queries.sql` in DBeaver and run it against the Chinook database.
3. Open `capital_budgeting.xlsx` in Excel to view the calculations.
